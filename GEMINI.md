# MBSTU Competitive Programming & Developer Ranking System

## Project Overview
A centralized system for MBSTU students to track problem-solving statistics across multiple platforms (Codeforces, CodeChef, AtCoder, LeetCode, Beecrowd) and generate unified rankings.

## Technical Stack
- **Backend:** Python + Flask
- **Database:** MySQL
- **ORM Policy:** NO ORM. Use raw SQL queries, prepared statements, and parameterized queries only.
- **Security:** Industry best practices (OWASP Top 10 mitigation).

## Architecture & Design Principles
- Strict adherence to Normalization (1NF, 2NF, 3NF).
- Explicit use of Primary Keys, Foreign Keys, and Constraints.
- Comprehensive indexing strategy.
- Secure session management and authentication.
